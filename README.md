# ГИРЯ — дневник тренировок

Адаптивное веб-приложение для тренировок с гирями на русском языке.

## Возможности

- Учёт подходов, веса, повторений и количества гирь.
- Расчёт тоннажа выполненных подходов.
- Редактирование программы и импорт CSV / JSON.
- История тренировок и графики тоннажа каждого упражнения за 4–8 недель.
- Антропометрия, ежемесячное напоминание при открытии и экспорт события календаря.
- Таймер отдыха, инструкции по упражнениям, варианты замены и поиск видео.
- Подключение Bluetooth-датчика со стандартным сервисом Heart Rate в поддерживаемом браузере.
- Экспорт резервной копии данных в JSON.

## Запуск

Приложение не требует сборки и сторонних JavaScript-зависимостей. Для локального запуска с установленным Python:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Для размещения на хостинге используйте содержимое `dist/`.

## Импорт программы

CSV без заголовка, поля разделяются точкой с запятой:

```csv
Махи гирей;3;16;15;1
Гоблет-присед;3;16;12;1
Жим гири стоя;3;16;10;1
```

Поля: название; подходы; вес одной гири в кг; повторения; количество гирь (1–2).
Для односторонних упражнений повторения указываются суммарно на обе руки.

JSON:

```json
[{"name":"Махи гирей","sets":3,"weight":16,"reps":15,"bells":1}]
```

## Хранение данных и ограничения

Данные хранятся в localStorage браузера этого устройства. Синхронизации между устройствами нет. Очистка данных сайта удаляет локальную историю, поэтому сохраняйте резервные копии через «Экспорт данных». Для полной копии используй «Восстановить историю». Импорт в разделе «Моя программа» по-прежнему загружает только программу.

Напоминания при закрытом приложении работают через импортированное событие календаря. Поддержка Web Bluetooth зависит от браузера и устройства; соединение с физическим датчиком не проверено. Для подключения необходим HTTPS или localhost. Шрифт Manrope загружается из Google Fonts.

## Дизайн «Железо + энергия»

Графитовый интерфейс с оранжевым акцентом, отдельным экраном текущего подхода, таймером отдыха и итогом тренировки. Новые файлы: dist/iron.css и dist/iron.js. Данные совместимы с первой версией (ключ girya-v1).



## Полное восстановление истории

Кнопка «Резервная копия» экспортирует программы, завершённые тренировки, черновики, план/факт, сложность и замеры. Новый локальный формат: girya-local-backup, schema_version 1, storage_format girya-v1; контрольная сумма SHA-256 проверяет целостность, но не подлинность. Это локальный формат до перехода на серверную модель из ТЗ.

«Восстановить историю» принимает прежний полный экспорт и новый формат. Лимит 20 МиБ, до 10 000 тренировок/замеров/черновиков и до 100 000 сериализованных подходов. Совпадающие данные пропускаются; расхождения разрешаются отдельно, по умолчанию остаются текущие данные. Программы сравниваются по слоту А/Б/В, тренировка вместе с черновиком — по дате, замеры — по дате. Эта версия хранит одну тренировку в день. Перед заменой сохраняется отдельная скачиваемая копия текущих данных. Старый страховочный снимок заменяется следующим.

Не загружай личные копии в публичный GitHub. Восстановление выполняется в браузере без отправки данных на сервер. Резервная копия не зашифрована — храни файл в безопасном месте.
