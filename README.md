# ГИРЯ — дневник тренировок

Адаптивное веб-приложение для тренировок с гирями на русском языке.

## Возможности

- Учёт подходов, веса, повторений и количества гирь.
- Расчёт тоннажа выполненных подходов.
- Редактирование программы и импорт CSV / JSON.
- История тренировок и графики тоннажа каждого упражнения за 4–8 недель.
- Антропометрия, ежемесячное напоминание при открытии и экспорт события календаря.
- Таймер отдыха, инструкции по упражнениям, варианты замены и поиск видео.
- Подключение Bluetooth-датчика со стандартным сервисом Heart Rate в поддерживаемом браузере.
- Экспорт резервной копии данных в JSON.

## Запуск

Приложение не требует сборки и сторонних JavaScript-зависимостей. Для локального запуска с установленным Python:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Для размещения на хостинге используйте содержимое `dist/`.

## Импорт программы

CSV без заголовка, поля разделяются точкой с запятой:

```csv
Махи гирей;3;16;15;1
Гоблет-присед;3;16;12;1
Жим гири стоя;3;16;10;1
```

Поля: название; подходы; вес одной гири в кг; повторения; количество гирь (1–2).
Для односторонних упражнений повторения указываются суммарно на обе руки.

JSON:

```json
[{"name":"Махи гирей","sets":3,"weight":16,"reps":15,"bells":1}]
```

## Хранение данных и ограничения

Данные хранятся в localStorage браузера этого устройства. Синхронизации между устройствами нет. Очистка данных сайта удаляет локальную историю, поэтому сохраняйте резервные копии через «Экспорт данных». Импорт JSON программы загружает только программу, а не полную историю из резервной копии.

Напоминания при закрытом приложении работают через импортированное событие календаря. Поддержка Web Bluetooth зависит от браузера и устройства; соединение с физическим датчиком не проверено. Для подключения необходим HTTPS или localhost. Шрифт Manrope загружается из Google Fonts.
